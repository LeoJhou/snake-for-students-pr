# 藥劑科 AI 課：班級貪吃蛇 repo

歡迎！這裡是今天的練習場——你的貪吃蛇要蓋在這裡。

## 怎麼開始

1. 到這一頁右上角按 Fork，把這個 repo 影印一份到你名下
2. 把你自己的那份 clone 回電腦
3. 開一條用你名字命名的分支，在裡面做你的貪吃蛇
4. 做完發 Pull Request 回來給老師

## 今天在這個資料夾裡會走過的流程

| 步驟 | 你會做什麼 |
|---|---|
| 1 | 開沙箱、降檔位，進 Plan Mode 把規格談清楚 |
| 2 | 說好檔案怎麼放：規則在 `src/game.js`、畫面在 `index.html`、測試在 `tests/` |
| 3 | 請 Claude 把貪吃蛇做出來，叫它開起來給你玩 |
| 4 | 玩得起來之後，回頭請它把遊戲規則寫成測試 |
| 5 | 用 frontend-design 把畫面重做一次，**再跑一次測試，規則不能被改壞** |
| 6 | 設一個 hook：以後它每次做完事，測試自己跑，過了才存檔 |
| 7 | 發 Pull Request 給老師 |

## 你不用打的指令

下面這些是 Claude 會用到的，你今天一行都不必自己打——它會在該跑的時候跑。
放在這裡是為了讓你看得懂它在做什麼。

| 指令 | 做什麼 |
|---|---|
| `pnpm install` | 裝好工具（第一次才要） |
| `pnpm test` | 跑測試 |
| `pnpm dev` | 開起來玩（會給一個 localhost 網址） |
| `pnpm build` | 打包成可以部署的 `dist/` |

## 有問題怎麼辦

先舉手，老師就在現場。課後問題貼到班級群組。

## 提醒

這裡的每一個 commit 都是一次存檔；你現在會用 git log 看到它們，就是這個功能。
