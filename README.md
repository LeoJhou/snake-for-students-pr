# 藥劑科 AI 課：班級貪吃蛇 repo

這裡是今天的練習場。你手上這份是你自己的**影印本**（fork），
怎麼改都不會動到老師的正本。

資料夾現在是空的，這是故意的——**貪吃蛇要由你和 Claude Code 從零蓋起來**。
每個人談出來的規格不一樣，所以做出來的貪吃蛇也不會一樣。

## 今天在這個資料夾裡會走過的流程

| 步驟 | 你會做什麼 |
|---|---|
| 1 | 進 Plan Mode，讓 Claude 訪談你，談出一頁 `PRD.md` |
| 2 | 交代檔案怎麼放：規則、畫面、測試各住各的 |
| 3 | 批准計畫，請它把貪吃蛇做出來，叫它開起來給你玩 |
| 4 | 玩得起來之後，回頭請它把遊戲規則寫成測試 |
| 5 | 用 skill 把畫面重做一次，**再跑一次測試，規則不能被改壞** |
| 6 | 設一個 hook：以後它每次做完事，測試自己跑，過了才存檔 |
| 7 | 發 Pull Request 回老師的正本 |

## 改壞了怎麼辦

把整個資料夾刪掉，請 Claude 再 fork 一次，一分鐘回到起點。
這也是為什麼今天可以放手亂試。

## 有問題怎麼辦

先舉手，老師就在現場。課後問題貼到班級群組。

## 提醒

這裡的每一個 commit 都是一次存檔；你用 `git log` 看到的那一串，
就是這個資料夾的病歷。
